# Calibreno 下一阶段更新文档

Calibreno 面向个人电子书书库。日常流程是导入已有书籍，复核重复项，补齐元数据，转换格式，再发送到阅读设备。下一阶段把这条流程作为默认体验，并用自有插件市场提供可选工具。「在网上搜书」作为市场首推插件。

## 1. 退出内置公开书源和默认在线找书入口

| 范围 | 更新任务 |
| --- | --- |
| 默认界面 | 未添加可搜索的 OPDS 书目时，侧栏隐藏「获取书籍」，移除获取更多书源的市场入口。 |
| 下载书籍的插件 | 移除内置古登堡书源和未发布的「中文维基文库精选」插件。市场和客户端拒绝声明 `bookSource` 的插件。已安装的书源插件停止运行，文件和配置由用户自行管理。 |
| 手动添加的 OPDS | 在「设置 → OPDS」添加目录后，可以从书库侧栏浏览并导入选中的书。添加可搜索的目录后，侧栏显示「获取书籍」。书库 OPDS 共享和 KOReader 的 Calibre 无线传送继续提供。 |
| MCP | 在库内搜索用 `search_books`，补元数据用 `find_metadata`。`find_books` 和 `download_book` 只访问用户手动配置且启用搜索的 OPDS 目录，遵循现有的 MCP 权限。按书目授权可后续单独评估。 |
| 可选网页搜索 | 「在网上搜书」安装后从已入库书籍的菜单按需调用。用户选定站点后在浏览器查这本书，收藏和自定义站点也放在插件里。 |

**验收**

- 不带 OPDS 书目的新安装或升级配置没有「获取书籍」入口，启动不请求预设公开书源。市场和客户端拒绝书源插件，已入库的书照常打开。
- 用已配置的私有 OPDS 样例完成浏览和导入，再从阅读器访问本机共享的书库。用旧配置升级验证书目地址、原书和插件设置可读。
- 验证有可搜索 OPDS 书目、无此类书目及 MCP 只读三种状态。删除或关闭书目的搜索后，旧会话中的搜索结果无法继续用于入库。

## 2. 运营自己的插件市场

Calibreno 负责目录、上架审核、推荐和发布渠道。市场可以同时收录上游已有插件、社区作者的插件和你自己开发的插件。首发可以先选用成熟插件，后续你再按优先级补上自己的版本。

| 插件来源 | 上架和维护方式 |
| --- | --- |
| **现有上游插件** | 项目的 `marketplace/plugins` 已经带有「在网上搜书」、ISBN 提取、中文简繁转换、EPUB 工具等移植版本。逐个检查许可证、权限和客户端兼容性，合格后可取用原版发布包，或按许可证从仓库源码打包。市场卡片记录原作者、源码和维护者，原版沿用已有插件 ID。 |
| **社区插件** | 把审核通过的项目登记到 `marketplace/community.json`。市场索引可以引用作者的 GitHub Release，作者负责版本发布，Calibreno 负责验证和推荐。 |
| **Calibreno 自研插件** | 由你开发并维护，使用自己的 ID，例如 `io.github.lyx5710317.calibreno.*`，单独发版。要接替已安装的上游插件时，先明确新旧 ID、设置迁移和作者归属，让用户知道会安装哪个版本。 |

桌面客户端从 `lyx5710317/Calibreno` 的 `marketplace` 分支读取 `marketplace.json` 和自有版本包。首发目录和推荐顺序由 `marketplace/catalog.json` 管理。上架记录包括作者、源码、许可证、最低客户端版本和权限。已发布包保留原版本，修改后递增版本号。改编或再分发上游插件时，逐一核对插件及依赖的适用许可证。

**验收**

- 用 `dalibre-plugin check` 验证首批包。新版客户端能从 Calibreno 的线上索引安装「在网上搜书」和一个 EPUB 工具。
- 在旧配置上核验已安装原版的 ID、授权、收藏和自定义站点。用测试索引和两个版本的包验收更新及权限变更提示。
- 线上市场支持标示维护状态和撤下推荐。网络失败时验证缓存目录与本地包安装。

## 3. 首推插件和自研优先级

截图中的 **「在网上搜书」** 是 Randy 的 **Search the Internet 1.2.1**。它从已入库的书读取书名、作者或 ISBN，打开豆瓣、Goodreads 等网站的搜索页。现有版本已经有站点收藏和自定义模板，适合直接作为首发推荐。 [插件源码与说明](../marketplace/plugins/search-internet/README.md)

| 优先级 | 插件 | 首发和后续开发 |
| --- | --- | --- |
| P0 | **在网上搜书** | 优先上架现有 1.2.1。验证豆瓣书名和 ISBN 搜索、站点收藏、自定义 URL 与默认浏览器打开。后续由你做中文站点配置，让常用站点排前，保留可编辑的外文站点和原有用户设置。 |
| P1 | **中文书目校对** | 首款自研插件。对选中的书离线校对，预览建议修改，把版次、卷次、译者和异常 ISBN 留给人工判断。之后再评估多个 ISBN 候选的提取。 |
| P1 | **中文简繁转换与 EPUB 工具** | 先精选现有简繁转换、合并、拆分和修整插件。后续按样例和使用反馈开发你需要的中文转换选项。 |
| P2 | **书目近似查重与书库规则** | 按需保留已有质量检查、系列管理和相似书目查重。自研可集中在中文书名、译本与作者差异，报告疑似重复并支持复核。主程序的全库查重负责比对文件内容。 |

内置 NeoDB 继续作为书目补全来源。批次恢复、PDF OCR 续跑、设备连接、传送设置和 MCP 由主程序负责，市场优先收录可以独立测试和更新的书库工具。

## 实施顺序

1. 移除下载书籍的插件，验收旧配置、手动 OPDS 与 MCP 的访问范围。
2. 用「在网上搜书」的现有版本做首发样例，验证上架、安装和升级，连同精选的 EPUB 与整理工具一起上线市场。
3. 发布自研「中文书目校对」，再根据使用反馈迭代中文校对规则和「在网上搜书」的中文站点配置。社区作者可以继续提供各自维护的插件。
