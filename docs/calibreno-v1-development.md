# calibreno 首版开发文档

calibreno 首版面向在 Windows 上整理个人 Calibre 书库的用户。一次导入形成一个批次，用户在「待整理」中复核重复文件、批量补元数据并查看结果。处理可以中断和恢复。简体中文覆盖桌面程序现有入口与本次新增流程，使用日常功能时无需依赖英文提示。

## 范围与开发基线

| 项目 | 首版要求 |
| --- | --- |
| 产品名称 | 对用户显示 `calibreno`。核对窗口标题、欢迎页、关于、版本更新页和应用包显示名。 |
| 运行环境 | Windows AMD64 为首轮验收环境。沿用 Go 1.27.3、MyGo 及当前桌面工程结构。 |

| 新功能 | 书库侧栏新增「待整理」。围绕导入批次提供查重对照、批量补元数据、恢复处理和结果查看。 |
| 汉化 | 选择「简体中文」或随系统解析到 `zh-Hans` 时，应用负责的桌面界面、操作反馈和错误提示使用简体中文。 |
| 交互基准 | Figma 文件定义主路径、先补资料和中途继续的交互。开发补足实际数据加载、异常和由用户确认的分支。 |

后续迭代项包括全库深度查重、自动合并译本、自定义整理规则、正文索引、内置阅读器和跨设备同步。批次视图使用现有书库的语言、出版社、标签等字段。首版按每次导入的任务管理进度。

### 全库查重

从侧栏「工具 → 全库查重」启动扫描。扫描先按格式和实际文件大小筛选，再比对文件的 SHA-256 指纹。书名和作者不同的文件也可以命中。同一书目的 EPUB 和 PDF 可以分别出现在不同的查重组中。结果沿用现有工具列表，显示已检查的书目和文件数量，可打开书目详情或重新运行。

扫描是只读操作，可从侧栏停止。遇到无法读取的文件时继续检查其余文件，结果页提供被跳过的文件详情。切换书库会停止原书库的扫描。应用内修改书库后，旧结果提示重新扫描。

## 从导入到批次结果

```text
添加文件或目录
  ├─ 无冲突 → 入库 → 检查是否需要补资料
  ├─ 同一书目下相同格式且内容完全相同 → 跳过并记录
  └─ 疑似重复 → 待查重 → 补格式、保留为新书、替换或跳过
                             └─ 新书入库后检查是否需要补资料
待补资料 → 统一设置或逐本查询 → 预览字段变化 → 确认写入
待查重、待补资料 → 稍后处理 → 从原批次继续
批次结果 → 查看已处理内容、失败原因及未决项
```

### 待整理与批次

- 一次文件选择或拖放形成一个批次。多个文件夹可以归入同一次选择。导入期间发起的下一次导入排队成为独立批次。
- 沿用递归扫描、格式识别、元数据提取和现有导入插件流程。同一路径在一次选择中只计一次。直接选择的不支持文件、无法读取的文件和有效电子书分别记录，能入库的文件继续处理。
- 在侧栏打开「待整理」后，默认显示当前书库最近一个可继续的批次，并可切换到可查看的历史批次。批次显示导入时间、来源名称、文件数、待查重数和待补资料数。
- 已入库书目用书名和作者作为默认检查项。导入流程识别出的系统占位值算缺项，保留用户输入的同名真实数据。缺封面、ISBN、简介等可选项可以在本批内筛出并补充，也可留空。用户可以确认「作者未知」并结束该条的整理。
- 「待查重」针对暂存文件，「待补资料」针对已入库书目。用户可以先处理任一队列。「稍后处理」、返回和关闭窗口保存已确认的结果及剩余待办。新批次默认保留其全部条目供复查。

### 查重对照与写入规则

| 识别结果 | 展示和操作 |
| --- | --- |
| 找到同一书目，已有同格式文件与新文件逐字节一致 | 默认跳过并记录「完全重复」。保留来源文件，在结果中关联已有书目，便于用户核对。 |
| 匹配书目缺少新文件的格式 | 显示「补充格式」建议。用户确认后给该书添加格式，保留原格式及原书目元数据。 |
| 同格式文件不同 | 显示尺寸、版本线索和文件对照。明确提供跳过、保留为新书或替换所选书目的同格式文件。替换须逐项确认。 |
| 书名与作者相同，ISBN、译者或出版信息提示不同版本 | 建议保留为独立书目。对照两侧可核验的信息，允许用户判断并选择已有书目或另建。 |
| 有多个候选书目，或者对照信息不足 | 显示候选列表和命中原因，确认目标后才应用操作。读取失败或候选失效时保留待办，支持重新检查。 |

使用现有 ISBN 和规范化标题、作者来缩小候选范围，并保留同名同作者的多个候选。内容完全重复的判断只比较候选书目的同格式文件。查重对照显示新文件和已有书目的书名、作者、ISBN、出版社、出版时间、格式、文件大小。有可信译者数据时显示字段，只有文件名线索时标明来自文件名。

补格式确认时重新检查目标格式仍为空。如果期间已出现同格式文件，转回待查重。替换确认记录目标书目、格式和当时的文件版本。应用时若目标书目或文件发生变化，要求重新核对。一次失败保留该条的暂存文件及失败原因，同批其他可处理项可以继续。

### 批量补元数据

**统一设置**面向选中的多本书，提供语言、出版社和追加标签三个入口。语言和出版社默认只填空值，标签在现有标签之上追加并去重。用户留空的统一设置字段跳过处理。出版信息或语言需要覆盖时，在预览中为相应书目逐项确认。

**按书查找**沿用已配置的元数据插件。每次批量操作选择一个来源，有可用 ISBN 时优先用 ISBN，否则用书名和可用作者。结果归到对应书目。只有一个可信匹配时可预选候选，多个候选或版本存在冲突时由用户选定。查询完成、没有匹配、等待选择、超时和来源配置缺失分别显示。失败或未选中的书可以单独重试，正常候选可以先应用。

预览按书列出字段、当前值、将填入的值和来源。沿用单书元数据编辑支持的字段，其中首版样本验收覆盖作者、出版社、语言，再加上统一设置中的追加标签。用户可以取消勾选个别字段。应用时读取当前书目，重新判断字段是否仍为空。与预览后发生的外部编辑冲突时，保留当前值并刷新预览。需要覆盖已有值的写入使用当前值作为确认依据。

「作者未知」是应用识别的缺项或用户确认的状态，取决于当前整理条目。书目语言按现有 Calibre 语言代码写入。现有 `zho` 对应界面中的「中文」，桌面界面语言仍是独立设置。

### 批次结果与恢复

结果页分别统计**新增书目、补充格式、替换格式、跳过重复、导入失败**，并列出补元数据的书目数和剩余待办。按文件计算导入进度，按书计算补元数据进度。格式补充、替换和元数据更新各自显示处理对象。完成项记入结果，失败项可打开查看原因或重试。

对正常退出、异常终止、切换书库、重复点击「应用」分别保留明确结果。回到批次时恢复当前待办与已完成动作。批次查询以当前书库为范围，新书库打开相同的书目 ID 时不会显示其他库的待办。完成批次仍可查看，未决和待重试项有继续入口。

### 批次数据和恢复

批次使用应用数据目录下的独立 SQLite 存储。书库数据仍由 Calibre 兼容层写入。持久化的时间、状态、动作和错误类别使用稳定值，界面按当前语言渲染。

| 记录 | 需要保存的内容 |
| --- | --- |
| 批次 | 批次 ID、书库标识、来源显示名、创建及更新时间。优先使用 Calibre 库 UUID。有旧库缺少 UUID 时使用规范化的绝对路径作为本机标识。 |
| 导入文件 | 批次内文件 ID、源文件路径、暂存路径、格式、比较所需的内容指纹、状态、候选或已写入书目引用，以及可重试的失败原因。 |
| 书目待办 | 批次 ID、书库标识、Calibre 书目 ID 和可获得的书目 UUID、待补字段、用户确认的完成状态。重新打开库时验证书目身份。 |
| 写入动作 | 对应条目、动作类别、目标和写入前依据、开始与完成状态。使用状态和实际写入结果区分已完成、可重试与待人工核对。 |

已成功导入的文件由书库管理。需要复核的文件及导入插件生成的临时产物，在释放本次导入临时文件前转入应用管理的暂存区。重启后可以继续处理，来源目录离线时也可以访问已暂存文件。只有动作达到可确定的终态后才清理对应暂存副本。导入前的来源文件由用户管理。

写入前先存动作意图及目标身份，调用现有书库写入逻辑，确认书目及实际文件后落下完成状态。恢复时先核对已知书目 UUID、目标格式和文件指纹，可以确认的动作补记结果。写入状态不明的动作回到待核对，并保留必要的暂存文件。重试使用相同动作记录，后台提交防止同一条目重复触发。替换格式需要在文件替换和数据库更新之间提供可恢复的原文件。旧格式保留到替换已经核验完成。

新增和编辑元数据沿用兼容层已有的 SQLite、目录命名和 OPF 更新流程。作者或书名变化引起目录重命名时，继续使用已有的迁移规则。应用关闭、书库切换和来源重试时，后台结果必须绑定原批次和原书库，迟到的查询结果不得覆盖另一批次的选择。

### 开发规则

1. 新旧的标题、菜单、按钮、工具提示、占位文字、无障碍名称、日期计数、进度、空状态、弹窗和错误摘要都走现有 MyGo 国际化机制。同步修改 `en.json` 与 `zh-Hans.json`，核对参数和复数表达式。生成的 `catalog_gen.go` 由 MyGo 更新。
2. 使用一致的界面术语。操作使用「保存」「待整理」「待查重」「待补资料」「补充格式」「保留为新书」「稍后处理」和「批次结果」。用「未知作者」等本地化占位展示程序生成的缺项。真实书名、作者、标签、文件路径和格式代码按其原值展示。
3. 首版市场验收清单以实际构建时的插件索引为准。内置与已纳入首版的插件覆盖应用显示的稳定文案及常见交互。对插件支持的中文资源优先使用其译文。外部书目资料、用户文件、第三方网页内容和诊断原文作为原始数据或详情呈现，界面提供中文入口和摘要。
4. 界面语言独立于书目语言和用户数据。保留已有语言选项及跟随系统设置。插件 ID、协议字段、MCP 工具名、书目语言代码和储存键继续承担程序间兼容，界面使用对应的中文显示标签。
5. 现有页面走查覆盖欢迎与开库、书架和列表、详情与编辑器、导入和批次、查询与设置、导出和邮件、OPDS 和设备、插件市场和插件弹窗、MCP 和更新。原生文件对话框、系统阅读器和外部服务由其自身语言环境决定显示文字，应用传入的标题、按钮和提示用中文。

## 测试与验收

在测试书库中预置《沙丘》PDF、《小王子》另一译本及供内容比对的原始文件。再导入 12 个文件，其中 8 个可直接入库、2 个为确认完全重复、1 个是应追加给《沙丘》的 EPUB、1 个是应保留为新书的《小王子》译本。为其中 3 本准备可选元数据，另保留至少一个用户已设置字段。在线查询测试使用固定候选，手动走查再验证实际配置的来源。

| 验收项 | 通过条件 |
| --- | --- |
| 主路径 | 完成两项复核和批量补资料后，结果为新增 **9 本**、补充 **1 个格式**、跳过 **2 个文件**，待处理为 **0 项**。检查库内书目与磁盘文件一致。 |
| 查重安全 | 同一 ISBN 不同格式可补文件，旧文件仍可打开。存在多个同名书目、不同译本或同格式不同文件时，能核对目标并选择。重复点击提交只执行一次。 |
| 顺序与恢复 | 查重到一半退出，重开后已确认的动作仍在，剩下的文件可以继续。先补资料再查重仍得到同一统计。切换书库再切回来可以恢复正确批次。 |
| 异常与重试 | 模拟文件锁定、源文件读失败、插件超时、目录暂时不可访问以及写入后尚未记完成即退出。界面提供中文原因和可继续的状态，恢复后不会重复新增书目或丢失原版文件。 |
| 元数据保护 | 批量查询按书预览字段变化，默认只填空。统一追加标签去重。模拟用户在预览后用 Calibre 修改字段，提交时保留后来写入的值并提示重新核对。 |
| 简体中文 | 首次启动和显式选择简体中文两种入口都检查。完整走过正常、空状态、无结果、加载报错、权限和重试路径，应用自有文案无漏译。格式缩写、真实书名与外部原文按预期展示。 |
| 回归 | 现有书库打开、单书编辑、拖放导入、格式读取、目录和插件入口继续可用。保留上游 Windows 已复现失败的基线，并检查新增或更改的行为没有回归。 |
