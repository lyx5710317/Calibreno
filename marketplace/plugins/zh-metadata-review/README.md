# 中文书目校对

Calibreno 自研的离线书目校对插件，适合在导入电子书后清理书名和作者字段。

## 使用

在书库中选中一本或多本书，右键选择「中文书目校对…」。Calibreno 会展示修改前后的差异，可以按书勾选应用。应用后可通过提示撤销。识别到版次、卷次、译者或异常 ISBN 时，书目会出现在「需要人工复核」列表。

## 首版规则

- 清理书名和作者字段的首尾空白，将书名中的全角空格归并为半角空格。作者之间的顺序和姓名内部的字符原样保留。
- 清理包住整个书名的单层《》。并列或嵌套书名号、带后缀样式的书名，以及书名号外的版次等附加信息按原文保留。例 `《城南旧事》` → `城南旧事`。
- 清理单层书名号外的电子书文件后缀，或中文书名中与书目已有格式相符的后缀。支持 EPUB、KEPUB（含 `.kepub.epub`）、MOBI、AZW、AZW3、PDF、TXT 和 FB2。例 `《城南旧事》.epub` → `城南旧事`。
- 对识别到的册卷、修订版、译者标记和现有 ISBN 的格式或校验位异常给出复核提示。对应的版次、卷次、译者和 ISBN 信息由用户判断。

处理范围仅限所选书籍的书目资料。插件离线读取这些字段，由 Calibreno 在确认后写入变更。
